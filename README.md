# ASPM For DAMN VULNERABLE WEB APPLICATION (DVWA)

This projects goal is to build a mock ASPM program using the DVWA as the application. The project utilizes the well known DVWA, an open source and intentionally vulnerable web application and OWASP tools such as ZAP and SCA and Github workflows to deploy DVWA via Docker then run the associated scans and generate a report and issues for analysis. At this time it is a work in progress.
